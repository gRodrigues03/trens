# 𝚝𝚛𝚎𝚗𝚜 👍

um aplicativo pra consultar a API dos trens que trafegam por aí num certo estadinho do sudeste brasileiro. 

sem conta, sem anúncios, sem coleta de dados. somente o próximo trem, grade horária e nada mais.

rápido e direto ao ponto. o APK final pesa uns `300kb`.

### ⚠️ estado atual do projeto
esse aplicativo é uns **80% vibecoded**. funciona perfeitamente bem, mas algumas respostas (ou ausência de) da API podem ser que não sejam tratadas.

foi feito via engenharia reversa do app em react native do android, tudo que foi analisado foram algumas chamadas à api e tratamento de dados. nenhum código proprietário foi utilizado nesse projeto.
